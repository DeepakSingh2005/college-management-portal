# College Management Portal

A full-stack college management system built with React, Node.js, Express, and MongoDB. The project provides separate workflows for admins, faculty, and students, with role-based login, profile management, notices, study materials, timetable access, exams, and marks management.

## Highlights

- Role-based portals for `Admin`, `Faculty`, and `Student`
- JWT-based authentication with protected API access
- Forgot password and reset password flows
- Admin management for students, faculty, branches, subjects, notices, exams, and admin accounts
- Faculty tools for uploading marks, managing materials, viewing student information, timetable access, and notices
- Student tools for viewing profile, timetable, study materials, notices, exams, and marks
- File upload support for profile images and academic assets
- Demo seed scripts for quick local testing

## Tech Stack

**Frontend**
- React 18
- React Router
- Redux
- Axios
- Tailwind CSS
- React Hot Toast

**Backend**
- Node.js
- Express
- MongoDB with Mongoose
- JWT authentication
- Multer for uploads

## Environment Variables

Create a `.env` file inside `backend/`:

```env
PORT=4000
MONGODB_URI=mongodb://127.0.0.1:27017/college-management-portal
JWT_SECRET=your_jwt_secret
FRONTEND_API_LINK=http://localhost:3000
NODEMAILER_EMAIL=your_gmail_address
NODEMAILER_PASS=your_gmail_app_password
EMAIL=your_gmail_address
```

Create a `.env` file inside `frontend/`:

```env
REACT_APP_APILINK=http://localhost:4000/api
REACT_APP_MEDIA_LINK=http://localhost:4000/media
```

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/DeepakSingh2005/college-management-portal.git
cd college-management-portal
```

### 2. Install dependencies

```bash
cd backend
npm install
cd ../frontend
npm install
```

### 3. Start the backend

```bash
cd backend
npm run dev
```

### 4. Start the frontend

```bash
cd frontend
npm start
```

The app should now be available at:

- Frontend: [http://localhost:3000](http://localhost:3000)
- Backend API: [http://localhost:4000](http://localhost:4000)

## Authentication

- Login is available for admin, faculty, and student users
- Protected routes use `Authorization: Bearer <token>`
- Password reset is handled through email links generated by the backend

## Notes

- Uploaded files are served from `/media`
- The frontend currently uses `frontend/src/App.js` as the active app entry imported by `frontend/src/index.js`
- A production frontend build is already present in `frontend/build/`
